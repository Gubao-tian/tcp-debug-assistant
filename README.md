# TCP 调试助手 · Pro

基于浏览器的 TCP 客户端 / 服务端调试工具。零第三方依赖，仅使用 Node.js 内置模块（`http` / `net` / `fs` / `path` / `os`）。

> 适用于协议调试、串口/网口报文联调、TCP 服务端联调等场景。浏览器负责交互，后端（Node）负责实际的 TCP 收发，两者通过 HTTP 指令 + SSE 实时推送桥接。

## 功能特性

- **双模式**：TCP 客户端 / TCP 服务端一键切换。
- **多编码收发**：文本 / HEX / HEX Dump，HEX 奇数长度实时拦截提示。
- **自动发送**：可设定间隔的定时发送，支持追加 `\r\n`。
- **自动重连**：客户端断线后按需自动重连。
- **多连接分标签**：服务端模式下按连接（`#id`）分标签查看日志。
- **接收关键字高亮**：日志正文按关键字高亮（文本模式）。
- **报文模板 / 发送历史**：`localStorage` 持久化，一键复用。
- **日志管理**：方向筛选 + 搜索 + 单条/全部复制 + 导出文本/HEX + 清屏。
- **实时统计**：接收/发送字节数、速率、记录条数。
- **明暗双主题**：视觉偏好持久化。

## 快速开始

```bash
# 1. 安装 Node.js（>= 14，建议 18+）
# 2. 启动服务
npm start
# 或
node server.js
```

默认在 **仅本机**（`127.0.0.1`）监听 `8080` 端口。浏览器打开：

```
http://127.0.0.1:8080
```

## 配置

绑定地址与端口均通过环境变量控制：

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `HOST`   | `127.0.0.1` | 监听地址。设为 `0.0.0.0` 允许局域网其他设备访问 |
| `PORT`   | `8080`      | 监听端口 |

示例：

```bash
# 仅本机（默认）
npm start

# 开放给局域网所有设备
HOST=0.0.0.0 npm start

# 指定某个网卡 IP
HOST=192.168.1.125 npm start

# 更换端口
PORT=9000 npm start
```

启动后终端会打印本机可访问的网址列表。

### 局域网联调注意事项

- 需将 `HOST` 设为 `0.0.0.0`（或具体网卡 IP）。
- 确保对方设备与本机**网络可达**（同一网段且未被 AP 隔离 / 客户端隔离）。
- 确保系统防火墙允许对应端口入站。

## 架构

```
浏览器 (index.html / app.js / style.css)
   │  POST /api（指令：连接 / 发送 / 启停 / 自动发送…）
   │  GET  /events（SSE 实时推送数据与状态）
   ▼
后端 server.js（Node http + net）
   │  TCP connect / listen / write / read
   ▼
目标 TCP 服务端 / 客户端
```

```
    └── app.js         # 前端逻辑
```
